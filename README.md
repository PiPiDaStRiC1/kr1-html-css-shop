# Учебный frontend-проект

## Текущий статус

Базовая HTML/CSS-структура проекта расширена с использованием Flexbox, CSS Grid, БЭМ-именование классов и базовое CSS-позиционирование.

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта

- `index.html` — главная страница;
- `css/style.css` — файл стилей;
- `images/` — папка для изображений;
- `.gitignore` — список файлов, исключённых из Git;
- `README.md` — описание проекта.

## Выполненные пункты 11–14

### 11. Flexbox и CSS Grid

В проект добавлены оба основных способа построения раскладки:

- Flexbox используется в шапке сайта для размещения логотипа и навигации;
- Flexbox используется в списке преимуществ;
- Flexbox используется внутри карточки товара;
- CSS Grid используется для вывода карточек товаров в сетку 3 колонки;
- добавлена адаптация сетки для меньших экранов.

### 12. Базовое БЭМ-именование классов

Для основных блоков применена схема БЭМ:

- `site-header`, `site-header__inner`, `site-header__logo`;
- `site-nav`, `site-nav__list`, `site-nav__item`, `site-nav__link`;
- `hero`, `hero__badge`, `hero__title`, `hero__description`, `hero__button`;
- `product-card`, `product-card__title`, `product-card__description`, `product-card__price`, `product-card__button`;
- `advantages-list`, `advantages-list__item`;
- `site-footer`, `site-footer__text`.

Также используются модификаторы, например `form-field--checkbox`.

### 13. Базовое позиционирование

В проекте показаны основные значения свойства `position`:

- `.hero` имеет `position: relative`;
- `.hero__badge` имеет `position: absolute` и позиционируется относительно `.hero`;
- `.site-header` имеет `position: sticky`, поэтому шапка остаётся сверху при прокрутке;
- `.support-button` имеет `position: fixed` и закреплён относительно окна браузера.
